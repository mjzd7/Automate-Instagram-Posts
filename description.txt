Automate-Instagram-Posts is a git-native, multi-account Instagram automation platform that generates and publishes quote-card images to Instagram (and optionally Threads) on a scheduled basis. The system eliminates hosted databases or caches by storing all state in git, enabling version-controlled content workflows with full auditability. A Next.js dashboard provides visual management of multiple accounts and scheduled posts, featuring granular control over posting schedules, content rotation, and performance analytics. The architecture supports parallel processing for scalable image generation and publishing workflows, utilizing headless browser automation and queued execution to handle high-volume demands. Built with TypeScript/JavaScript, the application emphasizes clean code practices, comprehensive testing, and adherence to maturity level L1 standards. Features include multi-account isolation with distinct authentication handlers, flexible schedule management with customizable intervals and recurrence patterns, and a visual dashboard for content planning and monitoring. The system is designed for maintainability with clear separation of concerns, reusable components, and extensible architecture supporting future enhancements like AI-generated quotes or advanced visual design generation.
